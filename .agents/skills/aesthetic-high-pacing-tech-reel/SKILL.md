```
│  "they'll change their glasses" / "psychological blocks"               │
```

## 4. Visual Overlays & Effects Component Recipes (Remotion / React)

### 1. Animated SVG Red Marker Pen Underline & Circle Loop

Simulates hand-drawn red ink annotating text in real-time:

```tsx
import React from "react";
import { interpolate, spring, useCurrentFrame, useVideoConfig } from "remotion";

export const RedMarkerAnnotation: React.FC<{
  startFrame: number;
  type: "underline" | "circle";
  width?: number;
  height?: number;
}> = ({ startFrame, type, width = 180, height = 50 }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const relFrame = Math.max(0, frame - startFrame);

  const drawProgress = interpolate(relFrame, [0, 12], [0, 1], {
    extrapolateLeft: "clamp",
    extrapolateRight: "clamp",
  });

  const pathLength = type === "underline" ? 220 : 480;
  const dashOffset = (1 - drawProgress) * pathLength;

  return (
    <svg
      width={width}
      height={height}
      viewBox={type === "underline" ? "0 0 200 20" : "0 0 200 80"}
      style={{
        position: "absolute",
        pointerEvents: "none",
        zIndex: 10,
      }}
    >
      {type === "underline" ? (
        <path
          d="M 5,12 Q 50,16 100,10 Q 150,6 195,14"
          fill="none"
          stroke="#DC2626"
          strokeWidth="4"
          strokeLinecap="round"
          strokeLinejoin="round"
          strokeDasharray={pathLength}
          strokeDashoffset={dashOffset}
        />
      ) : (
        <path
          d="M 30,40 C 25,15 175,10 175,40 C 175,70 20,72 25,42"
          fill="none"
          stroke="#DC2626"
          strokeWidth="4"
          strokeLinecap="round"
          strokeLinejoin="round"
          strokeDasharray={pathLength}
          strokeDashoffset={dashOffset}
        />
      )}
    </svg>
  );
};
```

### 2. Multi-Subject Geometric Color Card Popup (Scene 3)

Renders floating geometric cards with isolated B&W speaker cutouts:

```tsx
export const ColorCardCutout: React.FC<{
  color: string;
  imageSrc: string;
  delayFrames: number;
  x: number;
  y: number;
  rotation?: number;
}> = ({ color, imageSrc, delayFrames, x, y, rotation = 0 }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const relFrame = Math.max(0, frame - delayFrames);

  const popSpring = spring({
    frame: relFrame,
    fps,
    config: { damping: 14, stiffness: 200, mass: 0.35 },
  });

  const scale = interpolate(popSpring, [0, 1], [0.4, 1.0]);
  const opacity = interpolate(popSpring, [0, 1], [0, 1]);

  return (
    <div
      style={{
        position: "absolute",
        left: `${x}px`,
        top: `${y}px`,
        width: "260px",
        height: "320px",
        borderRadius: "28px",
        backgroundColor: color,
        transform: `scale(${scale}) rotate(${rotation}deg)`,
        opacity,
        boxShadow: "0 20px 40px rgba(0, 0, 0, 0.4)",
        overflow: "hidden",
        display: "flex",
        alignItems: "flex-end",
        justifyContent: "center",
      }}
    >
      <img
        src={imageSrc}
        alt="Speaker Cutout"
        style={{
          width: "100%",
          height: "100%",
          objectFit: "cover",
          filter: "grayscale(100%) contrast(125%)",
        }}
      />
    </div>
  );
};
```

### 3. Dual-Font Hybrid Text Display (Scene 5: "stays consistent")

Renders modern sans next to editorial cursive script on a cream background:

```tsx
import { loadFont as loadInter } from "@remotion/google-fonts/Inter";
import { loadFont as loadPlayfair } from "@remotion/google-fonts/PlayfairDisplay";

const { fontFamily: sansFont } = loadInter("normal", { weights: ["900"] });
const { fontFamily: scriptFont } = loadPlayfair("italic", { weights: ["900"] });

export const DualFontQuote: React.FC<{ frame: number; fps: number }> = ({ frame, fps }) => {
  const enter = spring({ frame, fps, config: { damping: 16, stiffness: 190, mass: 0.3 } });
  const slideY = interpolate(enter, [0, 1], [40, 0]);

  return (
    <div
      style={{
        display: "flex",
        flexDirection: "column",
        alignItems: "center",
        justifyContent: "center",
        width: "100%",
        height: "100%",
        backgroundColor: "#F5F2E3",
        transform: `translateY(${slideY}px)`,
        opacity: enter,
      }}
    >
      <div style={{ fontSize: "56px", fontWeight: 900, fontFamily: sansFont, color: "#111827" }}>
        but the way
      </div>
      <div style={{ display: "flex", alignItems: "baseline", gap: "16px", marginTop: "12px" }}>
        <span style={{ fontSize: "64px", fontWeight: 900, fontFamily: sansFont, color: "#111827" }}>

        </span>

            fontWeight: 900,
            fontFamily: scriptFont,

            color: "#111827",
            letterSpacing: "-0.02em",
          }}
        >
          consistent

      </div>
    </div>
  );
};
```

## 5. Velocity Motion Blur & Transition Physics

1. **Cutout Fly-In Velocity Blur**:
   When a cutout enters at high speed across a vector landscape, apply linear motion blur proportional to frame velocity:
   ```css
   filter: blur(8px);
   transform: translateX(-120px) scale(0.9);
   ```
2. **Apple Spring Damping Settings**:
   - Card Entrance: `damping: 14, stiffness: 200, mass: 0.35` (Instant snap, zero oscillation).
   - Text Word Pop: `damping: 18, stiffness: 220, mass: 0.28`.
   - Red Pen SVG Draw: Linear interpolation over 10–14 frames (`0.4s – 0.55s`).

## 7. Master Production Checklist for the 'AFTER' Edit Style

- [ ] **No Static Split-Screens**: The entire frame transforms into distinct cinematic states (Close-up → Vector Landscape → Navy 3-Card Studio → Newspaper Collage → Cream Paper).
- [ ] **Dual-Font Precision**: Clean heavy Sans-Serif (`Inter 900`) for conversational clarity + Editorial Script/Serif Italic (`Playfair Display Italic`) for high-value concept words.
- [ ] **Hand-Drawn SVG Annotations**: Red pen marker underlines & oval loops drawn with animated `strokeDashoffset` and marker SFX.
- [ ] **Newspaper Collage Backdrop**: Authentic newspaper clippings layered under text annotations for physical editorial depth.
- [ ] **Multi-Card Cutout Rotoscaling**: Speaker isolated, converted to high-contrast B&W, and staggered across vibrant geometric color cards.
- [ ] **Keyword Stress Color Blocking**: Key emotional/critical words take deep crimson (`#DC2626`) with text shadow glow.
- [ ] **Rapid Cut Cadence**: Visual state changes every **1.5 – 2.5 seconds** to maximize watch-time and viewer retention.
